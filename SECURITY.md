# Biztonsági szabályzat

## Sebezhetőség jelzése

Ha biztonsági hibát talál a Sys10 Technologies valamelyik rendszerében, kérjük, **ne nyisson róla nyilvános issue-t**. Írjon az [info@sys10.tech](mailto:info@sys10.tech) címre, és adja meg:

- az érintett rendszert vagy repót,
- a hiba reprodukálásának lépéseit,
- a lehetséges hatást.

A bejelentésre egy munkanapon belül válaszolunk. Kérjük, hogy a hibát a javításig ne hozza nyilvánosságra.

---

## Reporting a vulnerability

If you find a security issue in a Sys10 Technologies system, please **do not open a public issue**. Email [info@sys10.tech](mailto:info@sys10.tech) with the affected system or repository, steps to reproduce and the possible impact. We reply within one working day. Please keep the issue confidential until it is fixed.
